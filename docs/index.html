Economy Tokens.

Long chats cost more with every message, because Claude reads the whole conversation again. Economy Tokens tells you at the right moment, and shows where every token went.

Install in two commands View on GitHub

Three small tools

Built to stay out of your way.

⏱

Long-chat warning

Before each prompt, once a chat passes your limit, Claude suggests a fresh conversation with a short summary.

▤

Token footer

After every answer, see tokens used by the main model, helper agents and the advisor, side by side.

✦

Savings skill

Ask how to save tokens and Claude explains the habits: one topic per chat, delegate heavy work, short answers.

Install

Two commands.

claude plugin marketplace add FabioLima77/economy-tokens-claude-code
claude plugin install economy-tokens@economy-tokens-marketplace
  1. Run the two commands in a terminal, one at a time.
  2. Start a new conversation so the hooks load.
  3. Optional: set your own limit with ECONOMY_TOKENS_LIMIT (default 300000).

Control

Pause it, or remove it, any time.

claude plugin disable economy-tokens@economy-tokens-marketplace
claude plugin enable economy-tokens@economy-tokens-marketplace
claude plugin uninstall economy-tokens@economy-tokens-marketplace
