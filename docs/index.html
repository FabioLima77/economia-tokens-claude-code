Economia Tokens

Every answer in a long chat costs more, because Claude reads the whole conversation again. Economia Tokens warns you at the right moment and shows exactly where your tokens went.

View on GitHub Install in 2 commands
The problem

Long chats quietly get expensive.

A message in a 300,000-token conversation makes Claude read all 300,000 tokens again. Most people never see that number.

What it does

Three small tools. Nothing leaves your computer.

Long-chat warning

Before each prompt, if the chat passes your limit, Claude suggests a fresh conversation with a short summary.

Token footer

After each answer: tokens used by the main model, helper agents and the advisor, side by side.

Savings skill

Ask "how do I save tokens?" and Claude explains the habits: one topic per chat, delegate heavy work, short answers.

Preview

Everything you need, at the end of each answer.

Install

Two commands.

claude plugin marketplace add FabioLima77/economia-tokens-claude-code
claude plugin install economia-tokens@economia-tokens-marketplace
  1. Run the two commands in a terminal, one at a time.
  2. Start a new conversation so the hooks load.
  3. Optional: set your limit with ECONOMIA_TOKENS_LIMIT (default 300000).
Control

Pause it, or remove it, any time.

claude plugin disable economia-tokens@economia-tokens-marketplace
claude plugin enable economia-tokens@economia-tokens-marketplace
claude plugin uninstall economia-tokens@economia-tokens-marketplace
